# Sausage Lab — онлайн-каталог (HTML)

Открыть: `index.html` в браузере (нужен интернет: шрифты Google и библиотека перелистывания page-flip с cdn.jsdelivr.net).

- Язык по умолчанию — армянский. Переключатель ՀԱՅ / РУС / ENG внизу справа.
- Ссылки на конкретный язык: `index.html#hy`, `index.html#ru`, `index.html#en`.
- Ссылка на страницу: `index.html?p=5#ru` (p от 0 до 11).
- Листать: стрелки на экране, клавиши ← →, клик или свайп по странице.
- На телефоне показывается одна страница, на ноутбуке разворот.

## Как опубликовать
Загрузить всю папку `catalog-online` (index.html и папку img) на любой статический хостинг: Netlify, GitHub Pages, Cloudflare Pages или обычный хостинг. Адрес этой страницы нужно вставить в QR на странице 12 (сейчас QR ведёт на Instagram).

## Как обновить после правок макета
Правки в Claude Design → сказать «обнови онлайн-каталог»: страница пересобирается из холста.
